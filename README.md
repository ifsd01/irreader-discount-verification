## 常见问题

**优惠码填在哪里？**

结算页的输入框，填完必须点应用，然后看总价是否变化。没变化就说明这个码不适用于你选的版本或已经失效。

**irreader 和掌阅 iReader 是同一个东西吗？**

不是。掌阅 iReader 是电子书硬件和书城会员，irreader 是电脑上用的订阅阅读软件，两者没有关系。

**买断还是按年订阅？**

页面标什么就是什么。如果是限定时长的授权，到期后需要续费才能继续用；买断型则是一次付清。这一点务必在商品页确认，别按自己以为的模式下单。

**换电脑之后授权还能用吗？**

取决于授权是绑账号还是绑设备。绑账号的通常重新登录即可；绑设备的可能需要走解绑流程。买之前确认清楚，把兑换码留好。

**现在没有优惠码，是不是该再等等？**

如果你这几天就要用，等下去的时间成本高于可能省下的钱。如果你不着急，把页面存成书签，大促期间回来看一眼标价，这是唯一靠谱的蹲价方式。
